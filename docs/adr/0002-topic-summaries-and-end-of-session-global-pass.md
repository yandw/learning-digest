# Append-only Topic summaries; Session Digest from one end-of-session global pass

Summary artifacts are organized by **Topics** — semantic units identified on the Transcript's text layer (see GLOSSARY.md). During a Session, each summary tick appends new Topics (with Transcript time ranges) built from the new Transcript plus a short overlap tail of the previous tick; appended Topics are never rewritten. The Session Digest is produced by a single global pass over the full Transcript when the Session ends and does not consume the Rolling Summary.

Rejected alternative: the seed-era refining chain, which merged the previous rolling summary with the new transcript on a fixed 30-minute clock and kept only the latest merge. Over a 2–3 hour lesson the chain rewrites early content 4–6 times, losing detail and accumulating drift, and it has no time structure to anchor chapters, quotes, or the report. The global pass costs one call (lesson transcripts fit comfortably in the AI Provider's context window at cache-priced input rates) and its global view fixes the semantic misalignment that fixed-length Segment cuts create — misalignment no per-tick window can repair, since the audio-side cuts are already paid for by the exactly-once Speech Provider contract and cannot be re-sliced. The live Topic timeline is kept because the learner needs in-session feedback, but it is demoted to a view, not a Digest input; its append-only rule mirrors the Segment exactly-once contract and keeps resume trivial. Topic boundaries may span Segment boundaries; a Topic spanning two summary ticks renders as continuation sections live and is merged by the global pass in the final artifact.
