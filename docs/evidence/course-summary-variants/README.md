# 课程总结提示词对照

[详细总结版](detailed.md)和[章内关系图版](relationship.md)使用同一份小宇宙节目《【LLM】终章：在不确定中求变》的整集原始转写。每版的正文都由一次真实模型调用生成。样稿正文保留原始模型输出。[公开节目](https://www.xiaoyuzhoufm.com/episode/6afde79ea4a79edf137b6820)

- 详细总结版使用 `courseSummaryPrompt: "detailed"`。
- 章内关系图版使用 `courseSummaryPrompt: "relationship"`。
- 修改本地 API 配置并重启后，对同一资料重新点击「生成总结」。历史版本仍可在课程页面切换。

关系图版样稿中的 [SVG](relationship.svg) 经过人工匹配章节，并将三项条件汇总为原文所说的「至少两项」。当前 Web 使用已有图区呈现通过引用校验的图。此处提供 SVG 和章内位置作为对照。
