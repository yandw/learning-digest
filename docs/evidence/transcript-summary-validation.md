# 逐字稿整理与课程总结验证

使用百炼 qwen3.8-flash，经本地 API 的会话结束、逐字稿读取和课程总结生成入口验证。整理输入按约 1,000 字符分窗。课程总结复用前一次实跑的整理结果，各发送一次总结请求。三份样本均获得 HTTP 201。

## 结果

- 三份结果均保留全部原文字符顺序，来源映射覆盖各自的 100、143、12 条输入记录。英文录播有 1 个窗口、1,000 字符以原文展示。英文直播有 6 个窗口、8,974 字符以原文展示，约占全稿 18%。中文片段的两个窗口均整理成功。重试数由实跑响应离线重放窗口逻辑并核对逐句输出后得到。
- 排序录播总结涵盖冒泡、选择和归并排序。模型生成归并排序图，7 条候选连线中 5 条通过来源校验，可回查到基线分支、拆分、递归和合并输入。图仅覆盖原文中成功解析到出处的部分，正文给出了更完整的合并步骤。逐条验证了可引用的出处，模型仍负责判断引用与连线的语义关系。[MIT 官方录播](https://ocw.mit.edu/courses/6-100l-introduction-to-cs-and-programming-using-python-fall-2022/resources/6100l-lecture-24-version-2_mp4/)
- 直播总结过滤了开场聊天和互动指引，保留框架、案例和听众答疑。检查了 55 分 24 秒后的调查偏差相关问答。直播和中文片段此次均使用文字分层呈现。[Emory 官方直播回放与字幕](https://emorycenters4phtraining.emory.edu/surveillance-and-evaluation-webinar-recordings/) · [TVM Unity 主办方公开实录](https://hyper.ai/cn/news/28654)
- 英文样本使用公开字幕去掉大部分标点并按时间重组，中文样本来自公开实录 03:00–06:00 的真实音频转写，输入也去掉了标点。中文长直播、部署环境的实际浏览器回跳及不同窗口大小的对照仍待验证。现阶段保留约 1,000 字符的初始值，本轮样本仍能用一次请求完成课程总结。
