Learning Digest

Bring your own API keys

Keys stay in this Chrome profile and are sent only to your configured AI provider. This open-source extension has no developer server or analytics.

AI provider

阿里云百炼 · qwen3.8-flash Supported in this version

Learning Digest calls a large model through an OpenAI-compatible endpoint (by default Alibaba Cloud Bailian qwen3.8-flash) for rolling summaries, the session digest, translation, and note polishing. Create a Bailian API key.

Leave both fields empty to keep the Bailian defaults. A custom endpoint must speak the OpenAI chat-completions API. If its host is not dashscope.aliyuncs.com, add that host to host_permissions in manifest.json and reload the extension.

When you use AI features, your configured AI provider (Alibaba Cloud Bailian by default) receives the transcript and relevant session context. Review its terms and pricing before saving.

Speech Provider

Transcribes lesson audio into Transcript records

Create a Groq API key.

A custom base URL must speak the OpenAI audio transcriptions API; local faster-whisper servers work through the same slot. If its host is not api.groq.com, add that host to host_permissions in manifest.json and reload the extension. Known limitation: this release declares no optional permissions, so Chrome cannot grant a custom host at runtime and the manual manifest edit is the only way to reach one.

When you transcribe, the Speech Provider receives the Segment's audio. Credentials stay in this Chrome profile and are sent only to the provider you configured.

Session

While a Session is active, the AI Provider appends new Topics to the timeline whenever new Transcript reaches this length (and at least 10 records). Lower values cost more; 15 minutes suits a typical lesson.

How much audio each Segment captures in segment transcription mode; smaller values surface the transcript sooner (default 30 seconds). Allowed range is 5-60 seconds. This field has no effect in realtime transcription mode. Drag landings snap up to the next multiple of this length, so shorter lengths also shorten the audio a drag can skip.
